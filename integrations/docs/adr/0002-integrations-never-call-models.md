# ADR 0002: Integrations никогда не вызывает модели

- **Статус:** accepted
- **Дата:** 2026-08-03

Интеграции не имеют model provider, inference profile или provider secret.
Они не вызывают API моделей и не сохраняют ключи поставщиков.

Модельная обработка выполняется Local или будущей облачной обвязкой после приёма RawRound.
