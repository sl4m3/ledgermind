# ADR 0004: Core не имеет сетевого слоя

- **Статус:** accepted
- **Дата:** 2026-08-03

## Решение

Закрытый Rust Core не содержит HTTP-, TLS-, DNS-, cloud- или иных сетевых клиентов.
Он не получает URL, API-ключи, proxy-настройки или cloud credentials.

Все внешние взаимодействия выполняет Local или будущая облачная обвязка.
Local запускает Core с ограниченным окружением и, когда это обязательно настроено, в network namespace без сети.

## Следствия

- stdout Core содержит только IPC protocol, безопасные журналы идут в stderr.
- Сетевая изоляция диагностируется честно как `full`, `partial` или `unavailable`.
- Наличие сетевого crate в Rust Core считается архитектурной ошибкой.
