# ADR 0005: Core никогда не вызывает модели

- **Статус:** accepted
- **Дата:** 2026-08-03

## Решение

Core не вызывает модельные API и не владеет секретами поставщиков.
Модельные вызовы выполняет Local через настроенный пользователем `InferenceBroker`.

Core может создать типизированный `ModelTask` для операции слияния. В задачу входят только ожидаемые версии и минимальный `model_input`; внутренние фазы, метрики, пороги, формулы и полный граф знаний не передаются модели.

После результата модели Core самостоятельно проверяет версии, ограничения, ссылки и принимает окончательное доменное решение.

## Следствия

- API-ключи не попадают в Core, RawRound, spool или обычные журналы.
- Core не зависит от SDK/HTTP-клиентов поставщиков.
- Ошибки модели и повторные вызовы обрабатываются Local, а принятие результата остаётся за Core.
