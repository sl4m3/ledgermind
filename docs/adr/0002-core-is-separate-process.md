# ADR 0002: Core работает отдельным процессом

- **Статус:** accepted
- **Дата:** 2026-08-03

## Контекст

LedgerMind разделяется на открытые интеграции, Local service и закрытый Core.

## Решение

`ledgermind-core` реализуется на Rust и запускается как отдельный долгоживущий дочерний процесс.
Local общается с ним только через публичный versioned IPC по `stdin/stdout`.

Core получает только типизированные команды и гипотезы, принятые контрактом IPC. `RawRound` принадлежит открытому protocol и в Core не передаётся.

## Следствия

- Local не импортирует внутренние Rust-модули Core.
- Core не является Python-библиотекой Local; Python Core runtime не поставляется.
- Перезапуск и идемпотентность Core контролируются Local gateway.
- Закрытый бинарный Core может поставляться отдельно от Python-пакетов.
